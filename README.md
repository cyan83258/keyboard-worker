# Keyboard Worker · Pastel Pet

키보드를 치면 함께 반응하는 데스크톱 캐릭터입니다. 화면 한쪽에 떠서 타이핑에 맞춰 움직이고, 오래 쉬면 말을 걸고, AI를 연결하면 대화도 합니다.

- 실행: `app\KeyboardWorker.exe`
- 대상: Windows 10 / 11 (64비트)
- 내 설정이 저장되는 곳: `%LOCALAPPDATA%\KeyboardWorker` (프로그램 폴더에는 아무것도 저장하지 않습니다)
- 버전: 2.0.0 (설정 창 왼쪽 아래에 표시). 기능별 안내는 프로그램 안의 설정 → 시스템 → 사용 설명서에서 볼 수 있습니다.
- AI 연결 없이도 직접 쓴 대사(대사집)로 인사·재촉·랜덤 한마디·두 친구의 대화가 동작합니다.

## 기본 조작

| 동작 | 방법 |
|---|---|
| 홈 열기 | 캐릭터 더블클릭, 또는 레벨·코인 배지 클릭 |
| 한마디 보내기 | `♡ 한마디` 버튼, 우클릭 메뉴, 또는 `Ctrl+Alt+Q` |
| 메뉴 열기 | 캐릭터 우클릭 (트레이 아이콘 우클릭도 같음) |
| 캐릭터 옮기기 | 드래그 |
| 캐릭터 크기 | 캐릭터 위에서 `Ctrl + 마우스 휠` |
| 대사 담기 | 말풍선의 `♡` (대사 도감에 저장) |
| 말풍선 옮기기 | 말풍선 드래그 (우클릭 메뉴에서 자동 위치로 되돌리기) |
| 숨기기 / 보이기 | `Ctrl+Alt+H` |
| 휴식 시작 / 중단 | `Ctrl+Alt+R` |
| 설정 | `Ctrl+Alt+S` |
| 조용한 작업 모드 | `Ctrl+Alt+M` |

단축키는 설정 → 시스템 → 단축키 변경에서 바꿀 수 있습니다.

## 어디에 뭐가 있나

기능이 세 군데로 나뉘어 있습니다.

| 곳 | 여는 법 | 들어 있는 것 |
|---|---|---|
| **홈** | 캐릭터 더블클릭 | 하는 것과 보는 것 |
| **설정** | 우클릭 → 설정, `Ctrl+Alt+S` | 바꾸는 것 |
| **빠른 설정** | 우클릭 → 빠른 설정 | 자주 켜고 끄는 것 (체크박스) |

**홈**
- 오늘: 출석, 오늘 작업 시간(타이머·통계·휴식), 할 일 메모, 이번 주 목표, 미니 이벤트, 다가오는 기념일, 채팅·대화 검색
- 친구: 친밀도 단계, 캐릭터 개인 페이지(스탠딩 그림과 배경 위에서 마주 보고 대화 · 선물 건네기), 둘만의 페이지(두 캐릭터가 나 없이 대화), 두 친구의 관계·둘만의 장면·앨범, 이야기 퀘스트
- 수집: 대사 도감, 업적, 이야기책, 둘의 앨범
- 상점: 장식 아이템, 선물 뽑기(★~★★★★★) · 가방 · 선물 도감, 대사 팩, 2인 장면 자리 (코인 쓰는 곳은 모두 여기)

**설정** (왼쪽 위 검색칸에서 이름으로 찾을 수 있습니다)
- 캐릭터: 이미지, 표시, 프로필, 대사집, 음성, 프리셋(`.kwpreset`), 둘째 친구 배치
- 말 걸기·AI: 재촉 시작 시간, AI 자동 대사, 둘의 상호작용, 주변 알아보기, AI 연결(컨텍스트·응답 길이, 온도 등 세부 파라미터, 추론 강도, 상세도, 추가 본문·헤더), AI 사용량 · 성능
- 화면·소리: 테마 5종, 빠른 설정 · 상황 프로필, 대사 글꼴(TTF/OTF)과 크기, 말풍선, 타이핑 움직임, 쓰다듬기, 타이핑 소리, 음악
- 추가 모드: 모드 파일(JSON)이나 GitHub 주소로 테마 · 대사 팩 · 상황 프로필 · 캐릭터 페이지 모드 추가, 켜기/끄기 · 내용 보기 · 새로 받기 · 삭제
- 시스템: Windows 시작 시 자동 실행, 업데이트 확인(수동), 단축키, 프로그램별 예외, 백업 · 자동 백업, 저장 공간 관리 · 자동 정리, 오류 기록, 사용 설명서

**우클릭 메뉴**: 한마디 보내기 / 홈 열기 / 빠른 설정 / 상황 프로필 / 지금(숨기기 · 조용한 모드 · 휴식 · 위치 고정) / 설정 / 종료
## AI와 개인 정보

- AI 기능은 직접 연결한 제공사로 요청을 보냅니다. API 키는 Windows 계정에 묶어 암호화해서 저장합니다.
- AI에 전달되는 것: 캐릭터 프로필, (선택한 범위의) 대화 기록, 그리고 켜 둔 경우에만 — 맨 앞 프로그램의 이름과 오늘 쓴 시간, 재생 중인 영상·노래의 제목, 현재 시각과 요일.
- 화면 내용이나 입력한 글자는 읽지 않습니다.
- 작업 통계, 대사 기록, 오류 기록은 이 PC에만 남습니다.
- 남에게서 받은 파일을 가져올 때: 프리셋 파일(`.kwpreset`)은 이미지와 글자 수를 제한해서 읽고, 설정 백업은 설정·이미지·소리 파일만 받아들입니다. 백업은 AI 연결 주소까지 바꾸므로, 가져오기 전에 확인 창에 표시되는 주소를 살펴보세요. 직접 만든 백업이 아니라면 가져오지 않는 편이 안전합니다.
- 프리셋의 프로필과 프롬프트는 그대로 AI에 전달됩니다. 출처를 모르는 프리셋은 적용하기 전에 프로필 내용을 한 번 읽어 보세요.

## 설정 파일

`%LOCALAPPDATA%\KeyboardWorker` 안에 있습니다.

| 파일 | 내용 |
|---|---|
| `settings.json` | 화면, 소리, 단축키, 말풍선, 주변 알아보기 등 대부분의 설정 |
| `chat-settings.json`, `chat-history.json` | AI 연결·프로필과 대화 기록 |
| `character-presets.json` | 캐릭터 프리셋 |
| `pet-game.json`, `adventure-book.json` | 성장·상점·옷장, 친구 카드·이야기책·기념일·두 친구의 관계와 앨범 |
| `line-collection.json` | 대사 도감 |
| `stage.json`, `stage-chat.json` | 캐릭터 페이지의 그림·배경·대화 설정, 캐릭터 페이지에서 나눈 대화 (일반 채팅과 따로) |
| `mods\` | 추가한 모드 파일 |
| `progress.json` | 출석, 주간 목표, 미니 이벤트, 업적, 코인으로 연 것 |
| `usage-log.json`, `work-time.json`, `ai-usage.json` | 작업 통계와 AI 사용량 |
| `images\`, `sounds\`, `fonts\` | 등록한 이미지·소리·글꼴의 사본 |
| `backups\` | 가져오기·정리 전에 남기는 설정 백업, `backups\auto\`에는 자동 백업 |
| `error-log.txt`, `startup-timing.txt` | 오류 기록, 시작 속도 기록 |

설정 파일을 읽지 못하면 기본값으로 시작하되, 원본은 `파일이름.broken-날짜`로 보관하고 오류 기록에 남깁니다.

## 배포와 업데이트 (만드는 사람용)

사용자는 설정 → 시스템 → **업데이트 확인** 버튼으로 새 버전을 받습니다 (수동 전용, 자동 확인·자동 설치 없음). 그 버튼이 동작하려면 한 번만 준비하면 됩니다.

1. GitHub에 **공개** 저장소를 만들고 이 폴더를 올립니다 (`app`, `dist`, `bin`, `obj`는 `.gitignore`로 빠집니다).
2. `KeyboardWorker.csproj`의 `<UpdateRepository>`에 `계정이름/저장소이름`을 적습니다. 비워 두면 업데이트 버튼이 꺼진 채로 나갑니다.
3. 새 버전을 낼 때마다:
   - `KeyboardWorker.csproj`의 `<Version>`을 올립니다 (예: `2.0.0` → `2.1.0`).
   - `tools\make-dist.ps1`로 `dist\KeyboardWorker-win-x64.zip`을 만듭니다.
   - GitHub 저장소의 Releases → *Draft a new release*에서 태그를 `v2.1.0`처럼 버전과 같게 짓고, 그 ZIP을 첨부한 뒤 게시합니다. 본문에 적은 글이 사용자에게 "바뀐 내용"으로 보입니다.

업데이트는 GitHub의 "최신 릴리스"에서 이름에 `win-x64`가 들어간 ZIP을 받아, 크기와 체크섬을 확인한 뒤 프로그램 파일을 바꾸고 다시 시작합니다. 중간에 실패하면 바꾼 파일을 되돌립니다. 태그의 버전이 실행 중인 버전보다 높을 때만 새 버전으로 봅니다.

**모드 배포**: 모드 파일(`이름.kwmod.json`)을 공개 저장소에 올리고 그 주소를 알려 주면, 사용자는 설정 → 추가 모드에서 주소를 붙여 넣어 설치하고 '새로 받기'로 갱신합니다. 모드는 데이터라서 테마·대사 팩·상황 프로필·페이지 모드까지만 됩니다. 완전히 새로운 화면이나 동작은 프로그램에 넣고 위의 업데이트로 내보냅니다.
## 소스에서 빌드하기

.NET 10 SDK가 필요합니다.

```
powershell -ExecutionPolicy Bypass -File tools\build-app.ps1
```

빌드, 단위 테스트, `app\` 반영을 한 번에 합니다. `-Smoke`를 붙이면 모든 창을 한 번씩 여는 검사도 실행합니다. 다른 사람에게 줄 묶음은 `tools\make-dist.ps1`로 만듭니다 (프로그램 파일과 .NET 런타임만 들어가고, 개인 설정은 들어가지 않습니다).

| 폴더 | 내용 |
|---|---|
| `Core` | 시작, 저장과 백업, Windows 연동, 프로그램·음악 인식 |
| `Pet` | 캐릭터 창과 말풍선, 이미지, 타이핑 반응, 캐릭터가 먼저 하는 말(`AutoLines.cs`), 음성 |
| `Ai` | AI 요청, 채팅, 자동 대사 |
| `Model` | 설정·게임·이야기 데이터 |
| `Windows` | 설정 창들과 테마 (`Pastel.cs`) |
| `SelfCheck` | 앱 안에서 도는 검사 (`--smoke-test`) |
| `tests` | 단위 테스트 프로젝트 |
| `tools` | 빌드 스크립트 |

창 없이 실행하는 관리 명령은 `Core\Maintenance.cs` 맨 위에 정리되어 있습니다 (`--image-diet`, `--clean-unused` 등).
