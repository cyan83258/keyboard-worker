이 폴더에 넣은 PNG / JPG 그림은 상점에서 코인으로 사는 악세서리가 됩니다. (프로그램에 함께 들어가 배포됩니다)

1. 파일 이름만으로 등록하기
   위치_이름_가격.png 로 이름을 지으면 됩니다.
     예) head_고양이 귀_300.png   -> 머리에 쓰는 '고양이 귀', 300코인
         face_하트 선글라스_450.png -> 얼굴에 쓰는 '하트 선글라스', 450코인
         neck_빨간 리본.png        -> 목에 하는 '빨간 리본', 가격은 기본값 300코인
   위치는 head(머리) · face(얼굴) · neck(목) · body(몸) · effect(오라) 중 하나입니다.
   위치와 가격은 빼도 됩니다 (빼면 머리 · 300코인).

2. 크기와 위치까지 맞추기 (선택)
   그림이 캐릭터 위에 어긋나 보이면, 이 폴더에 accessories.json 을 만들어 파일마다 적어 줍니다.
     [
       { "file": "head_고양이 귀_300.png", "name": "고양이 귀", "slot": "head", "price": 300, "level": 1,
         "description": "쫑긋한 고양이 귀", "width": 42, "x": 0, "y": -6, "rotation": 0, "behind": false }
     ]
   - width: 캐릭터 너비에 대한 크기(5~200%)   - x, y: 기준점에서 옮기는 정도(%)   - rotation: 회전(도)
   - behind: true 면 캐릭터 뒤에 그립니다   - level: 이 레벨부터 살 수 있습니다

   숫자를 쉽게 찾는 법: 프로그램의 상점 · 옷장 → '+ 내 장비 등록'에서 그림을 올리고 위치를 맞춘 다음
   '배치 값 복사'를 누르면, 위와 같은 한 줄이 복사됩니다. 그대로 붙여 넣고 가격만 고치면 됩니다.

3. 넣은 뒤
   tools\build-app.ps1 을 실행하면 app\accessories 에 반영되고, 상점에 나타납니다.

- 권장: 배경이 투명한 PNG, 256×256 ~ 512×512.
- 한 번 내보낸 뒤에는 파일 이름을 바꾸지 마세요. 이름이 곧 아이템의 번호라서, 바꾸면 이미 산 사람의 옷장에서 사라집니다.
- 이 폴더는 GitHub에 공개되고 배포 파일에 들어가므로, 직접 만들었거나 배포해도 되는 그림만 넣으세요.
