Keyboard Worker
===============

실행 방법
- 폴더 전체를 원하는 위치에 풀고 KeyboardWorker.exe 를 실행하세요.
- .NET 런타임이 함께 들어 있어 따로 설치할 것이 없습니다. (Windows 10 / 11, 64비트)
- 처음 실행할 때 Windows가 "PC 보호" 경고를 띄우면 "추가 정보" → "실행"을 누르세요.
  서명되지 않은 프로그램이라 나오는 안내입니다.
- Program Files 처럼 쓰기가 막힌 폴더보다는 문서 폴더나 D: 드라이브 같은 곳에 두세요. (업데이트할 때 필요합니다.)

사용 방법
- 화면 오른쪽 아래에 캐릭터가 나타나고, 처음 한 번 짧은 안내 창이 뜹니다.
- 캐릭터 더블클릭: 홈 (오늘 · 친구 · 수집 · 상점)
- 캐릭터 우클릭: 한마디 · 홈 · 빠른 설정 · 숨기기/휴식 · 설정
- 기능별 설명은 프로그램 안에 있습니다: 홈 아래쪽의 "사용 설명서" (또는 설정 → 시스템 → 사용 설명서)
- 캐릭터 이미지, 프로필, AI 연결(API 키)은 설정에서 직접 등록합니다.
- AI를 연결하지 않아도 직접 쓴 대사(설정 → 캐릭터 → 대사집)로 인사·재촉·랜덤 한마디가 동작합니다.

업데이트
- 설정 → 시스템 → "업데이트 확인"을 누르면 새 버전이 있는지 보고, 있으면 그 자리에서 내려받아 바꿉니다.
- 버튼을 누를 때만 동작하며 자동으로 확인하거나 설치하지 않습니다. 설정과 캐릭터는 그대로 남습니다.

내 설정이 저장되는 곳
- %LOCALAPPDATA%\KeyboardWorker
- 프로그램 폴더에는 아무것도 저장하지 않으므로, 폴더를 지우거나 새 버전으로 바꿔도 설정은 남습니다.
- 설정 → 시스템 → "설정 백업 · 자동 백업"에서 ZIP 파일 하나로 내보내고 가져올 수 있습니다.

삭제
- Windows 시작 시 자동 실행을 켜 두었다면 먼저 끄고, 프로그램 폴더와 %LOCALAPPDATA%\KeyboardWorker 폴더를 지우면 됩니다.

버전 확인
- 설정 창 왼쪽 아래에 버전이 표시됩니다.
